# Kullanıcı Brief'i

## Konu
**Görünen Agent, Görünmeyen Harness**

Sunumun temel ayrımı: kullanıcının "agent" olarak gördüğü kısım ile, arka planda o agent'ı işler kılan iskelet (harness) arasındaki fark. Harness; tool execution, context window yönetimi, prompt katmanları, retry/error handling, observability gibi görünmeyen ama belirleyici bileşenleri içerir.

## Hedef Kitle
- **Birincil**: Yapay Zeka Mühendisliği bölümü teknik üniversite öğrencileri
- **Bilgi seviyesi (1-5)**: 3 — temel ML/NLP bilgisi var, LLM kavramına aşina, ama agent harness'larının iç işleyişine henüz hakim değiller
- **Beklenti**: Akademik bilgiyi pratik mühendislik gerçeğiyle birleştiren, perde arkasını gösteren bir anlatım

## Ton
- **Etkileyici**: ezberden anlatım değil, "şimdi bunu duydun, kafanda bir şey değişti" hissi yaratan
- **İlgi çekici**: hikaye akışı, sürpriz bilgi, görsel zenginlik
- **Odakta tutucu**: tempo değişimi, soru-cevap yapısı, aha anları

## Format
- **Dil**: Türkçe — ancak teknik terimler (agent, harness, tool, context, prompt, observability, vb.) doğal akışta İngilizce kalabilir, zorla Türkçeleştirme yok
- **Derinlik**: Orta (kavramsal anlama + pratik örnekler, ama derin sistem mimarisi tartışmasına girmeden)
- **Slayt sayısı**: Sabit değil — içerik dolu olmalı, slayt sayısı içeriğin gerektirdiği kadar
- **Tahmini süre**: 20-30 dakika aralığı (içerik yoğunluğuna göre Strategy belirler)
- **Format**: 16:9

## Özel Notlar
- İçerik kullanıcı tarafından sağlanacak — Knowledge Synthesis web araması yerine kullanıcı malzemesini sentezleyecek
- Görsel açıdan "perde arkası" temasını destekleyici metaforlar uygun olabilir (sahne/kulis, ön yüz/iskelet, görünen/görünmeyen katmanlar)
